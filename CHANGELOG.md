# Changelog

## 0.1.0 — Initial release

- Python backend: `post_llm_call` hook generates follow-up suggestions via `ctx.llm`
- Desktop UI: suggestion pill in `composer.underside` area
- Configurable: enable/disable, context window size, cooldown
- Auto-dismiss on typing, session switch, or new turn
- Multi-language support (en, es, ja, zh)
